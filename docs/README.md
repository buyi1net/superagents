# 项目文档

本目录保存 `superagents` 的长期项目文档，面向项目维护者以及需要理解插件机制和制度演进过程的读者。正式发布的跨 Agent 规则以 [skills/constitution/](../skills/constitution/SKILL.md) 中的源稿为准；本目录负责解释机制、记录复盘，并保存只适用于本仓库维护工作的操作说明。治理测试文档是项目级测试 skill 的细则来源，不复制到正式发布规则中。
