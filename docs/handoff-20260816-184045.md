## 决策与原因
- 长模板的硬性结构不再交给模型凭记忆重建：Claude 已经证明“完整读取”不等于“五分钟后仍能完整重建”。
- 局部强制提示只能降低已读章节的遗忘概率，不能保护被整体遗忘的章节。
- “维护结果验收”与“本规范执行验收”保持两个概念：前者检查项目产物，后者检查人制定的契约是否完整落地。
- 同一执行模型的自述、自建清单和“已完成”结论不能单独证明硬性结构验收通过。
- 在本次复杂治理任务中，同一 DeepSeek V4 Flash 接入 Claude Code 后比 Pi 占用更多上下文且执行质量更差；该结论只限定本次对照范围，不直接推广到所有模型和任务。
