# 模拟测试规范

> 测试 / 演示 / 模拟场景下额外遵守。
> 目的是用最快的组合跑通流程,不浪费等待时间;正式任务不受本规范约束。

## 模型偏好(用户指定,勿改)

* 测试 / 演示 / 模拟测试场景,默认使用以下模型组合:

| Agent | 模型 | 思考等级 |
| --- | --- | --- |
| pi | glm5.2 | 最低 |
| codex | gpt5.5 | 最低 |

* **仅限测试用**。正式任务按任务需要选模型,不受本表限制。

* 启动测试用 agent 时,主动指定上述模型与最低思考等级,不要用 agent 默认模型;默认高推理模型(如 gpt-5.6-sol xhigh)在演示场景会显著拖慢节奏。

* 若当前 agent 无法指定模型或已用默认模型启动,先说明原因再继续,不要让演示在未知模型配置下进行。
