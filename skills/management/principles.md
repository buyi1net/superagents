# 判断原则

> 机器检查（gov.mjs check）管不住的判断题在这里。量小是刻意的：能机械判定的都进了 check，读本文只在需要判断时发生。

## 项目根判定

1. 用户明确指定的目录优先；用户专门建立或选择的目录即使为空也视为项目根；
2. 没有指定时，按最近的 `AGENTS.md`、版本库边界、项目清单、源码或 README 确定，不凭目录名猜；
3. 位于项目子目录时继承所属项目根；嵌套项目取当前任务实际维护的最小完整边界；
4. 在主目录、桌面、下载目录、盘符根或系统临时目录且无上述依据时，项目根未确定：只读检查可继续，产生文件或外部副作用前先问用户。

## 粒度原则（防过度执行）

- 空目录零治理：没有内容就没有入口文件，manifest 也先不登记；
- 少量内容只记 manifest：目录职责一行 entry 即可，不建局部 AGENTS.md；
- 目录满足以下任一条件才升级局部入口（AGENTS.md）：条目多到 README 表格失去导航价值；有独立操作流程且 check 规则覆盖不了；多个会话反复在此目录犯同类错误；
- 治理文件数量与内容价值挂钩：参考说明、索引全部是生成物，手写治理文件只剩根 AGENTS.md 一份是常态。

## 角色词典

| role | 边界要点 |
|---|---|
| reference | 外部材料，只读参考；每个参考项必须有来源、快照、许可证、生命周期；副本不入库 |
| docs | 长期文档，全部入索引；临时报告不算 docs |
| source | 业务源码与独立交付单元 |
| scripts | 可重复执行的构建、测试、同步、迁移脚本 |
| build | 最终交付物：版本目录、压缩包、校验文件；不是开发区 |
| temp | 可再生内容：构建暂存、实验、截图、缓存；主体不入库 |
| design | 设计源文件、原型、设计令牌 |
| tests | 跨模块、端到端的项目级测试与测试数据 |
| data | 源数据与备份：只读的原始数据、快照、导入备份；是流程输入而非可再生物，不得用 temp 代替 |
| archive | 已退出当前流程但需追溯；默认只读 |
| custom | 以上都不匹配时的显式标记，note 必须写明实际职责 |

## 工作模式

- **建设**（新项目）：init 后再产生主体内容；
- **接入**（既有项目首次治理）：adopt 吸收现状，TODO 即债务，逐项消化；
- **维护**（已治理项目日常）：只执行项目内规则 + check，不回读本 skill；
- **修复**（check 红灯）：只消化红灯指向的缺口，不借机重塑其它结构；
- **审计**（用户要求）：跑 check 出报告，无写入权限时只报告不自修。

既有项目已有能自治的结构时不强制迁移：沿用其入口与命名，gov.mjs 可作为附加校验单独引入。

## 参考材料判断

- 更新副本的触发：项目要对照新版本做升级评估；来源发布了与本项目有关的重大修订；参考说明记录的快照与实际采用的依据不一致。其余情况保持固定快照；
- 废弃：生命周期改「已废弃」+ 日期与原因，删除本地副本，保留 manifest 记录（索引不删，标记废弃）；
- 只供本次查看的下载物进 temp，不作参考副本登记。

## 备份与源数据判断

- 备份、快照、导入的原始数据归 `data`：它们不可再生（删了就没了），又未被当前流程淘汰（不是 archive）；
- 命名用人类看得懂的中文或惯用词（如 `data/书签备份/`），不自造英文生僻名；
- 双写式备份（桌面一份给人、项目内一份给流程）需在 manifest 目录 note 中登记外部副作用，否则下一个 Agent 无法对账；
- 从备份恢复前先确认浏览器/服务已停止写入，恢复到副本验证后再覆盖。

## 归档语义

- 判断依据是内容职责（退出当前流程、仍需追溯），不是目录名；
- 命名 `名称-版本-YYYYMMDD-HHmm`，时间取实际归档时刻；
- 记录：来源版本（git 提交）、用途与原因、恢复方法；恢复前确认兼容性，恢复到副本，不直接覆盖当前内容。

## 交付晋级

顺序：暂存组装 → 副本验证 → 晋级 + 校验和。check 只验终态（存在性 + 校验覆盖），过程顺序靠此原则执行；交付物形成后的任何改动都使先前验证失效，必须重走流程。

## 模型惯性对策

- 元数据捕获绑进动作（add-reference），不指望事后回忆；
- 会话边界必跑 check：开工一次（对账），收工一次（验收）；
- 欠账是工单不是耻辱：允许先干活后补登记，但债务不得跨会话隐形。

## 残余风险（check 管不住的）

- 字段填错语义（分类标错、来源写错）：机器验不出真伪，靠复核；
- hook 与闸门可被绕过：结构把失败面压到单字段级，压不到零；
- 生成段外的人类散文仍可能过期：标记外内容是人的领地，check 只管标记内。
